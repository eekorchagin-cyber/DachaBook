# Народные приметы о погоде и сельскохозяйственных работах

Даты — по новому стилю, без привязки к году.

| Дата | Описание приметы |
|---|---|
| **7 января** | **Рождество.** Оттепель считалась предвестием ранней тёплой весны, большие сугробы — урожайного года. |
| **14 января** | **Васильев день.** Туман связывали с хорошим будущим урожаем. |
| **19 января** | **Крещение.** Ясный морозный день предвещал засушливое лето, пасмурный со снегом — обильный урожай. |
| **29 января** | **Пётр-полукорм.** Хозяйственный ориентир: проверяли, достаточно ли оставшихся кормов до весны. [1] |
| **1 февраля** | **Макарьев день.** Капель обещала раннее наступление весны. |
| **6 февраля** | **Аксинья-весноуказательница.** По погоде дня судили о весне: ясный день обещал погожую весну. |
| **15 февраля** | **Сретение.** Капель считали знаком хорошего урожая пшеницы. |
| **21 февраля** | **Захарий-серповидец.** Хозяйственный обычай: осматривали и готовили серпы к будущей жатве. [1] |
| **14 марта** | **Евдокия-весновка.** Солнечная тёплая погода предвещала раннюю весну, холодная и ветреная — затяжную. [2] |
| **17 марта** | **Герасим-грачевник.** Грачи, сразу занявшие старые гнёзда, предвещали быстрое наступление весны. |
| **22 марта** | **Сороки.** Холод в этот день связывали с последующими сорока холодными утренниками. [1] |
| **7 апреля** | **Благовещение.** Дождь обещал грибное лето, гроза — тёплое лето и урожай орехов. |
| **9 апреля** | **Матрёна-полурепница.** Хозяйственный обычай: отбирали репу для получения семян. |
| **14 апреля** | **Марья — зажги снега.** Обильное половодье считали предвестием хорошего роста трав. [3] |
| **8 мая** | **Марк.** Ясную погоду связывали с хорошим урожаем яровых культур. |
| **14 мая** | **Еремей-запрягальник.** Погожий день обещал благоприятную погоду во время уборки зерновых. |
| **18 мая** | **Арина-рассадница.** Традиционный срок высадки капустной рассады на грядки. |
| **19 мая** | **Иов-огуречник.** Обильная утренняя роса при ясной погоде обещала урожай огурцов. |
| **22 мая** | **Никола вешний.** Народный календарь связывал этот срок с посадкой картофеля. |
| **24 мая** | **Мокей мокрый.** Дождливый день предвещал сырое лето. [3] |
| **2 июня** | **Фалалей-огуречник.** Обилие еловых шишек считали признаком будущего урожая огурцов. |
| **7 июня** | **Иванов день.** Обильную росу связывали с хорошим урожаем. |
| **18 июня** | **Дорофей.** Тёплая ясная погода обещала крупное зерно. |
| **25 июня** | **Пётр-поворот.** Дождь предвещал мокрый сенокос, ясная погода — благоприятную заготовку сена. [3] |
| **7 июля** | **Иван Купала.** Обильная роса обещала урожай огурцов; с этим временем связывали начало сенокоса. |
| **10 июля** | **Самсон-сеногной.** Дождь предвещал затяжное ненастье, мешающее сушке сена. |
| **21 июля** | **Прокопий-жатвенник.** Созревание черники считали признаком готовности ржи к уборке. [1] |
| **1 августа** | **Макрида.** Дождливая погода обещала сырую осень, сухая — погожую. |
| **7 августа** | **Анна-холодница.** Холодное утро считали предвестием морозной зимы. |
| **12 августа** | **Сила и Силуан.** Традиционный ориентир начала сева озимой ржи. [1] |
| **14 сентября** | **Семён-летопроводец.** Хозяйственный ориентир завершения сева озимых; запоздалый посев связывали с плохим урожаем. |
| **27 сентября** | **Воздвижение.** Ожидали усиления холодов; начинали рубить и заготавливать капусту. [4] |
| **14 октября** | **Покров.** Снег предвещал раннюю зиму, сухая ясная погода — позднюю. |
| **17 октября** | **Ерофеев день.** Усиление холода считали признаком приближения устойчивых морозов. |
| **21 октября** | **Трифон и Пелагея.** Наступившую стужу связывали с продолжительными холодами. [4] |
| **14 ноября** | **Кузьма и Демьян.** Мороз в этот день предвещал холодную зиму. |
| **20 ноября** | **Федот.** Неровный, нагромождённый лёд на реке обещал богатый урожай зерновых. |
| **22 ноября** | **Матрёна зимняя.** Иней на деревьях предвещал мороз, туман — оттепель. |
| **27 ноября** | **Филиппов день.** Иней считали знаком хорошего урожая овса в следующем году. [4] |
| **1 декабря** | **Платон и Роман.** По погоде этого дня пытались определить характер предстоящей зимы. |
| **4 декабря** | **Введение.** Считалось, что снег, выпавший после этой даты, сохранится до весны. |
| **12 декабря** | **Парамон.** Обильный снегопад связывали с хорошим ростом трав следующим летом. |
| **19 декабря** | **Никола зимний.** По силе мороза судили о будущих зимних холодах. [5] |

В источниках встречаются разные местные варианты примет, а иногда и смешение старого и нового стиля. Поэтому в своде оставлены выбранные календарные ориентиры, а не попытка дать примету на каждый день.
